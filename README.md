# 🎲 Dice Game

A simple and fun 2-player dice game built using **HTML, CSS, and JavaScript**. Refresh the page to roll the dice and see who wins!


## 🌐 Live Demo

🎲 Play the game here:  
👉 [Dice Game](https://parthl001.github.io/Dice-Game/)

---

## 🚀 Features

* 🎯 Random dice roll for both players
* 🏆 Automatic winner detection
* 🤝 Displays draw when both dice are equal
* 🎨 Styled UI with background image and custom fonts
* ⚡ Instant result on page refresh

---

## 🧠 How It Works

* When the page loads:

  * Two random numbers (1–6) are generated using JavaScript
  *
* The dice images update dynamically based on these numbers
* The game compares both values and updates the result:

  * Player 1 Wins 🥇
  * Player 2 Wins 🥇
  * Draw 🤝

---

## 💻 Technologies Used

* HTML5 → Structure of the page 
* CSS3 → Styling and background design 
* JavaScript → Game logic and DOM manipulation
